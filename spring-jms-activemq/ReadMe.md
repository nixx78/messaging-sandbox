# Проект песочница для работы с AMQ очередями
Для работы используется embedded AMQ.

## Примеры с основными случаями использования:

* Отправка сообщения в очередь (queue)
* Отправка сообщения в topic (сообщение получают 2 слушателя)
* Отправка сообщения в синхронную очередь, получение синхронного ответа (ответ в temp queue)
* Отправка сообщения в очередь и получение ответа в другой очереди (синхронизация по ID)
