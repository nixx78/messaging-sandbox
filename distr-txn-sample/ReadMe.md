# Проект песочница для изучения распределенных транзакций

## Описание 

* Для поддержки транзакций подключена библиотека: <artifactId>transactions-spring-boot3-starter</artifactId>
* Окружение для запуска (MySQL & AMQ) находится в ./docker

## Основные случаи использования

В рамках одной транзакции (метод указан как @Transactional) следующие действия:
* Сохранение данных в базу данных
* Отправка сообщения в очередь

Ожидаемое поведение, это отправка сообщения и сохранение в базу только в том случае, если нет ошибок.
